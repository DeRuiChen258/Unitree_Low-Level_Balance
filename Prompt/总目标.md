你现在是一个资深机器人系统工程师、强化学习基础设施工程师和推理服务工程师。请在当前工作区内，基于现有代码仓库，设计并实现一套面向 Unitree 具身智能的“低层决策层”原型系统。该系统需要把 Jev-like 结构化决策模型、rl_infra 训练与评测闭环、vLLM 在线推理服务三者整合起来，形成一个可运行、可扩展、可测试的工程化方案。

## 总目标

实现一个面向 Unitree 机器人低层行为决策的原型框架，要求满足以下目标：

1. Jev-like 模型不直接输出自然语言，而是输出结构化决策结果。

2. rl_infra 负责数据、训练、校准、评测、阈值与回退策略。

3. vLLM 负责在线推理服务、结构化输出约束和并发访问。

4. 最终系统面向 Unitree 低层行为决策层，而不是直接控制底层电机力矩。

5. 产出一套可运行的最小可行版本（MVP），以及清晰的目录结构、接口定义、测试脚本和使用说明。

## 任务边界

请严格遵守以下边界：

- 不要把 Jev-like 模型设计成聊天模型。

- 不要把模型直接接到底层电机控制环。

- 代码风格要求清晰、模块化、可测试。

## 推荐架构

请按以下三层实现：

### 1. 决策层：Jev-like Decision Model

职责：

- 接收机器人状态、环境特征、任务上下文、候选行为集合。

- 输出结构化决策，而不是文本。

- 输出内容至少包括：
  
  - primitive / action_id
  
  - confidence
  
  - risk
  
  - need_human_review
  
  - fallback_action
  
  - optional: score / probability / reason_code

约束：

- 输出必须是类型安全的结构化对象。

- 支持多个决策头，例如：
  
  - motion_primitive_head
  
  - safety_veto_head
  
  - recovery_head
  
  - escalation_head

### 2. rl_infra 层：训练 / 校准 / 评测中台

职责：

- 数据集管理

- 训练任务配置

- 校准策略

- 阈值策略

- 评测指标

- 回退与人工复核逻辑

- 日志与轨迹回放

至少支持以下指标：

- accuracy

- precision / recall / F1

- calibration error 或其近似实现

- confidence reliability curve

- latency

- fallback rate

- unsafe decision rate

### 3. vLLM 层：在线推理服务

职责：

- 暴露统一 API

- 支持 structured outputs

- 支持 choice / JSON schema / grammar 约束

- 支持批量推理和并发请求

- 为决策层提供服务化入口

注意：

- vLLM 不是控制器。

- vLLM 只负责推理服务与输出约束。

- 真正执行动作的模块必须与推理模块解耦。

## 面向 Unitree 的业务定位

这个系统面向 Unitree 具身智能的低层行为决策层，但不要写成底层伺服控制。

建议定义的行为层级如下：

- 站立 / 保持

- 前进 / 后退

- 左转 / 右转

- 停止

- 小步恢复

- 降级保护

- 请求人工接管

- 切换行为原语

请将这些行为抽象成可配置的 action set / primitive set，而不是写死在逻辑里。
