你现在是一名机器人运动控制、强化学习、具身智能和机器人系统工程方向的科研工程师。请基于当前仓库和现有 Unitree G1 仿真环境，实现一个“Unitree G1 自主弯腰拾取物体 + 大幅弯腰时自主调整脚步形成弓步保持重心 + 拾取后恢复站立”的多动作耦合平衡系统。

本项目的核心目标不是单纯生成一个固定动作，而是研究：

“机器人在执行弯腰、伸手、抓取等上肢/躯干动作时，如何根据实时重心稳定性自主调整双脚位置，使机器人始终保持可恢复的稳定状态。”

最终形成一个类似“具身智能小脑低层决策 + 运动控制”的研究原型。

# ============================================================

一、核心研究问题

围绕以下问题组织整个实验：

RQ1：  
G1 在执行大幅躯干前倾时，如果不调整脚步，稳定裕度会如何变化？

RQ2：  
机器人能否根据实时 COM / 支撑域 / ZMP / 足端状态自主判断是否需要调整脚步？

RQ3：  
当弯腰程度超过安全阈值时，机器人能否自动把双脚调整为前后错开的弓步姿态，从而恢复稳定裕度？

RQ4：  
“弯腰 → 调步 → 伸手 → 抓取 → 起身 → 恢复”这种连续动作，是否可以由多个低层行为原语动态组合，而不是一个固定轨迹完成？

RQ5：  
加入一个 JEV-like structured decision layer 后，是否可以让机器人根据当前状态自主选择：

- 继续弯腰

- 减小弯腰

- 调整步距

- 左脚前移

- 右脚前移

- 进入弓步

- 停止动作

- 恢复站立

- inverse kinematics

- whole-body controller

- task-space controller

四、实验动作流程

最终 Demo 必须完成完整动作：

阶段 0：准备

- G1 正常站立

- 双脚平行

- 身体稳定

- 目标物体位于机器人前方地面附近

阶段 1：目标检测/任务触发

- 读取目标物体位置

- 计算机器人与目标之间的相对位置

- 判断是否需要弯腰

- 生成 pickup task

阶段 2：开始弯腰

- 躯干逐渐前倾

- 髋关节和膝关节协同运动

- 机器人保持足底接触

- 手臂开始朝目标移动

阶段 3：稳定性监测  
实时计算：

- COM projection

- support polygon

- ZMP

- trunk pitch

- trunk angular velocity

- foot contact

- capture point / extrapolated COM 等可选指标

阶段 4：自主判断  
如果当前稳定裕度足够：

继续弯腰。

如果稳定裕度降低：

降低弯腰速度。

如果稳定裕度接近安全边界：

执行 footstep adjustment。

如果稳定裕度超过危险边界：

停止上肢动作并进入 recovery。

阶段 5：自主弓步  
根据目标方向选择：

左脚前移  
或  
右脚前移

使机器人形成前后错开的双脚支撑。

注意：

“弓步”不是预先固定好的动作。

必须根据：

- COM

- target position

- support polygon

- current foot pose

- predicted COM  
  动态决定。

阶段 6：重新获得稳定  
脚步调整完成以后：

重新计算稳定裕度。

只有当稳定裕度恢复到安全区间后：

才允许继续弯腰和伸手。

阶段 7：伸手

- 控制肩、肘、腕

- 末端执行器接近目标物体

- 尽可能保持躯干稳定

阶段 8：抓取  
实现：

- 接近

- 接触

- 抓取

- 抬升

如果当前 G1 模型没有真实可用的灵巧手模型：

允许实现一个 research mock grasp：

使用：

- gripper joint

- weld / equality constraint

- mocap attachment

- 或简单 contact constraint

模拟物体被拿起即可。

不要为了真实手部模型阻塞整个实验。

阶段 9：起身  
执行：

- 释放弯腰姿态

- 恢复躯干

- 膝关节伸展

- 脚步重新调整到稳定站姿

阶段 10：完成  
输出：

pickup_success = true

并记录整个 trajectory。

七、稳定性指标

优先实现以下指标。

1. COM projection

计算：

p_COM = [x_com, y_com]

然后投影到地面。

2. Support Polygon

使用左右脚接触区域建立支撑多边形。

3. COM Margin

计算 COM projection 到 support polygon 边界的最小距离。

4. ZMP

实现简化 ZMP。

5. Capture Point

在条件允许时实现：

x_capture = x_com + v_com / omega

作为预测性步态调整依据。

# ============================================================

八、自主弓步逻辑

这是整个实验的核心。

不要使用简单：

if pitch > threshold:  
step_forward()

需要实现状态预测。

建立：

BalancePrediction

例如预测未来 Δt：

future_com  
future_com_velocity  
future_capture_point  
future_margin

然后：

if future_margin > safe_threshold:  
CONTINUE

elif future_margin > warning_threshold:  
BEND_SLOW

elif future_margin > critical_threshold:  
PREPARE_STEP

else:  
STEP / LUNGE

进一步根据目标位置判断脚步方向。

例如：

target_x > robot_x  
且  
future_com 前移

则考虑：

STEP_FORWARD_LEFT  
或  
STEP_FORWARD_RIGHT

如果是 lateral instability：

选择：

STEP_LEFT  
STEP_RIGHT
